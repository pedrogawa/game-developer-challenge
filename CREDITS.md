# Asset credits

## Pirate Battle challenge package

All ships, ship parts, projectiles, effects, tiles, HUD elements, menu graphics, spritesheets, reference images, branding, and WAV files used by this project were supplied in the repository's `assets/` directory as part of the Pirate Battle challenge package.

No external visual assets, audio assets, icon libraries, or web fonts were added. The interface uses system fonts (`Georgia`, `Times New Roman`, and the browser `system-ui` stack).

The supplied package does not include a separate license file. Its assets are therefore used only under the terms of the challenge in which they were provided. This project does not claim ownership of those resources.
